# Jewels by Richa

E-commerce site for **Jewels by Richa** — anti-tarnish, waterproof jewellery. Next.js 16 + Tailwind v4.

```bash
npm install
npm run dev      # http://localhost:3010
```

- Storefront: `/` · Admin: `/admin` (demo login — any password)
- Currently a **UI-only build** with dummy data kept in `localStorage`; Admin → *Reset demo data* restores the seed.
- Backend / database plan: see [BACKEND_PLAN.md](BACKEND_PLAN.md) and [prisma/schema.prisma](prisma/schema.prisma).
